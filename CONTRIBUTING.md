# Contributing

Small, focused fixes and documentation improvements are welcome. Open an issue before proposing large features. This is a personal showcase; response times and ongoing feature support are not guaranteed.

1. Follow the setup instructions in the README using your own disposable database.
2. Read `AGENTS.md` for layout requirements and the installed Next.js documentation for changed APIs.
3. Make a focused branch and add a regression check when changing behavior.
4. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
5. Explain the problem, resulting behavior, and validation in your pull request.

Keep all sample achievements explicitly fictional. Submit only material you can license under MIT, and never include credentials, production exports, personal photos, or identifying documents. Review database changes for data loss; no production database access is needed to contribute.
